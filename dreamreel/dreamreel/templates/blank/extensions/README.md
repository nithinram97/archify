# Extensions

Python files here add features to this film: new kinds of characters, hair, extras, moods,
gestures, actions, props, sets, camera shots or voice engines. Each is a small class; once the file
is here, the new feature can be used in cast, set and scene files, and it appears in dreamreel
studio's menus.

Start one with, for example:

    dreamreel extend prop cake
    dreamreel extend gesture dance
    dreamreel extend character robot

and see everything available with `dreamreel plugins -v`.
